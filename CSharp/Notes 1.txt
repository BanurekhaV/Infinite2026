- Parse : converts a string input, if not possible throws exception

- TryParse: tries to convert a string. if yes, returns the converted values as output and Boolean true, else false. But does not throw any exception

- Boxing n unboxing

- Nullable concept and null coalescing 

- Debugging options

- Methods in C# have parameters of the following type :
  1. value
  2. reference
  3. out
  4. parameter array 
         (params keyword helps in giving a variable number of arguments, separated by comma, or zero arguments)
         Only one params is allowed per function
         params keyword should be the last in the method declaration
     


- Implicit Types

   var  : has to be initialized at the time of declaration
          it will implicitly convert to the initialized value
          cannot change after initializing

   dynamic : declaration and initialization can be at different times
             does not convert to the initialized type at the compile time, instead will convert at runtime
             can be changed with different types of values, hence can become an overhead on performance
             try to minimise usage of dynamic
