Covariance : allowing objects, variables, parameters of more derived types to be assigned to less derived types
- is a concept in C# that helps in preserving assignment compatability
- is an implicit operation

 Eg : Object initialization
     Shape shape = new Rectangle();

Contravariance : Is the reverse assignment of covariance compatabilty
                allowing objects, variables, parameters of less derived types to be assigned to more derived types
                is applied more to parameters to functions than object assignment
   Rectangle rectangle = (Rectangle)new Shape();

void func1(Rectangle rect)
{
}

func1(Shape shape)

Base Type : generally has common information (less derived but bigger object)
Sub Types : have common info + specific info (more derived, but smaller object)
