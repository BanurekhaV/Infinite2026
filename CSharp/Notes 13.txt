Extension Methods : a concept that allows us to add new methods to the existing class or structure without modifying the source code of the original type. Also this does not need any special permission nor re-compilation of the original type
- Are methods that are always marked static, but when they are bound with other class/structure, they convert into non-static 
- We can also add extension methods to sealed classes
- When an extension method is defined with the same name and signature of the existing method, then the compiler will resolve only the existing method, and not the extension method (Hence extension methods do not support overriding)


- Scenarios like a sealed class or when the source code is not available with us, but we want to add new features(methods) to them, then we go for extension methods

LINQ - Language Integrated Query 
       is a uniform syntax for retrieving data from different sources and formats
       it is integrated in C#
       eliminates mismatches between programming lang and database by providing a single query interface for all types of sources

Linq 
queries returns results as objects

1 Query Syntax/Expression : similar to SQL for database
                            starts with a from clause and ends with either a select or groupby

  Syntax: from <rangevariable> in <IEnumerable><IQuerybale><Collection>
             <standard query operators> <lambda expressions>
<select or group by operator>  <result formation>

2. Method Syntax/Expression/Extensions/Fluent
  - also known as fluent syntax uses extension methods to form results
  - also includes lambda

Query syntax is easier to read, but method syntax are more powerful way of writing queries
Both do not support all query operators.
Always prefer query syntax over method until requirements demand

Nested Classes : are logically grouped classes
                 provides encapsulation
                 Readable code

We cannot access the members of the inner class with an outer class object
We can access outer class members inside the inner class with the outer class object
We can inherit the outer class
We can inherit the inner class only with reference to the outer class and the inner class be public/ or internal


Partial Methods :
- Declared with partial keyword
- Must always exist inside a partial class or partial struct
- Can have a declaration and an optional implementation
- If no implementation is provided, declaration will be removed by the compiler
- Must always return only void type
- Cannot be associated with access modifiers
- Can be static, but cannot be virtual, abstract, async, extern
- out parameters are not allowed
