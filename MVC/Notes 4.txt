Model Binding : is a mechanism which converts the URL segment into method parameters
    - The parameters can be primitive type or complex type
    - It acts like a bridge between http request and the action method, and maps the values from the url which may be as below :
     
 Model Binder uses default Model Binder mapping (rules for mapping)
  1. Request.Form[]  : if the request is POST
  2. RouteData.Values[] : if the value is in the route
  3. Request.QueryString[] : if the values are concatenated in the url as query string
  4. Request.Files[]  : if the file is being uploaded

Custom Model Binding : In situations where the UI controls are different from the Model properties, we may have to custom bind using the IModelBinder interface and implement the BindModel() Method


Bundling and Minification : is a process of making use of static files viz, .js, .css etc that are required by the application
 - This would be rendered after compressing the resources to be included
 - We can add any no. of resources to the bundle collection of the BundleConfig.cs


Validations : are model validations that help posting the valid data to the server.
             - This avoids wrong/malicious/junk data from entering the server
             - Through client side validations, we can avoid unnecessary round trips to the server with wrong data
             - We should engage in both client and server side validation to be safer.
