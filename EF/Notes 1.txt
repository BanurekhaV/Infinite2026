Entity Framework (EF) : is an object relational mapper(ORM) that enables dotnet developers to work with relational data with domain specific objects  
  - it is an open source framework for ADO.net
  - Helps in building faster applications

Types of Entities:
1. POCO Entities (Plain Old CLR Objects) - A Poco entity is a class that does not depend on any framework base class, and is a simple .net clr class

2. Dynamic Proxy Entities : (POCO Proxy) - Dynamic proxy is a runtime proxy class that wraps the POCO Entities

Database Context : Is an instance of the database, that allows individual / group changes to be written back to the database as a single unit.

Life Cycle of an entity object / Entity States

1. Added : The entity is marked added, when we perform insertion. The entity will be tracked by the context, but the data will not be available yet in the database. When we call the SaveChanges(), the state will become Unchanged 

2. Deleted : The entity is marked deleted, when we perform deletion. The entity will be tracked by the context, and the data will be available in the database. When we call the SaveChanges(), the state will become Detached

3. Detached : The entity is not being tracked by the context. An entity will be in this state as soon as it is instantiated

4. Modified : This state is when an entity is being modified. The entity is tracked by the context and the data will be available in the database. Some or all property values can be changed. On SaveChanges(), the entity will be Unchanged

5. Unchanged : The entity has either been inserted with or modified with values

Entity Framework supports 3 approaches to ORM
1. Database First : (Existing Database) - Relations/Tables are simply mapped to classes as Models

2. Code First : (No existing Database) - Classes get mapped to relations using a technique called migrations

3. Model First : Create Models in the design mode, then convert the models to classes, and the classes to realtions
