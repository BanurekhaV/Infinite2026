Network of Information
A Uniform naming scheme for locating a resource on the web (URI)
Protocol, for accessing the named resources over the web (HTTP)
Content/hyper text - for easy navigation amongst the resources (HTML)

W3C. org - World Wide Web Consortium

HTML : Hyper Text Mark Up Lang
       It is known as a publishing lang of WWW
       Made up of predefined tags, elements, attributes and values

Versions : 1,2,3,4,5  (Non semantic and Semantic tags)

Semantic Tags : are tags or elements that describe the meaning both to the browser as well as the developer
  <form><table><article><section>

Non Semantic Tags : are tags that do not convey anything
  <div><p><h1><span>

Paired and Unpaired tags

HTTP : Hyper Text Transfer Protocol
       is a network protocol, used to deliver virtually any resource on the web
       is an HTTP Client , as it sends/receives request to and from the server
       operates on a default port 8080, to listen to requests

Scalable Vector Graphics (SVG)
 - are defined using xml format
 - all elements to be properly closed
 - are case sensitive and hence any element/attributes which are predefined is to be given in lower case
 - all attribute values must be within " ", including numbers

Ways to integrate SVG with HTML
 - inline SVG, using <svg> element
 - External SVG , using <object> <img>
 - SVG as background
