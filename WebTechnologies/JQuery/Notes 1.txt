jQuery : is a JavaScript library
         is a light weight library (write less, do more)
         to enable usage of javascripts on the web
         it includes lots of common task, that would have usually taken lines of code, wrapped into methods that takes up a single line of code
         simplifies complicated scripts like Ajax calls and DOM Manipulations

$(selector).action()

$ - is a sign to either access / define jquery
selector - to find html element/tag
action - is a method used to perform some tasks on the html elements

Eg: $(this).hide();

Events : Mouse, Keyboard, documents/windows

methods : hide(),show(),toggle(), fadein(), fadeout(), slide(),animate(), callback(), chaining etc
