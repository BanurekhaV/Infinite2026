jQuery : is a JavaScript library
         is a light weight library (write less, do more)
         to enable usage of javascripts on the web
         it includes lots of common task, that would have usually taken lines of code, wrapped into methods that takes up a single line of code
         simplifies complicated scripts like Ajax calls and DOM Manipulations

Ajax with Jquery :

what is a jquery ajax method()
- ajax() is used to do an ajax(asynchronous http) request
- provides more control of the data, sending or response data
- allows error handling during a call, using callbacks of either success or failure

some basic parameters to be passed on call
 -type : specifies get or post method
 -url : specifies the url to send the request to
 -contentType:what type of content is used to send data to the server 
 -datatype : the datatype expected as server respone
 -data:specifies the data
 -success(result,status,xhr)- is a callback that should be run when success
 -error(xhr,status,error) -  is a callback that should be run when request fails
