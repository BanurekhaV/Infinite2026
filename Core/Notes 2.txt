EFCORE : .Net does not support Visual Designer for DB Model and Wizard. Hence we will have to scaffold the dbcontext using reverse engineering ( where entity model classes and a dbcontext based on the existing database is created)

1. EFCORE DB first: create an ASP.net MVC application

Packages to include
 - Microsoft.EntityFrameworkCore.SqlServer  ( this package includes Microsoft.EntityFrameworkCore and Microsoft.EntityFrameworkCore.Relational)
 - Microsoft.EntityFrameworkCore.Tools  (design)

next we need to make an entry in the appsettings.json file as below :

{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*",
  "ConnectionStrings": {
    "DBConnection": "Server=Laptop-tjj7d977;Database=Northwind;Integrated Security=true;TrustServerCertificate=True;"
  }
}

next move to PM console and type as below

PM> Scaffold-DbContext "Server=Laptop-tjj7d977;Database=Northwind;Integrated Security=true;TrustServerCertificate=True;" Microsoft.EntityFrameworkCore.SqlServer -OutputDir Models

Observe that the Models folder is full of model classes and the dbcontext class

Note : Whenever there is any change made to the database schema, then we can use the scaffold with -F option

PM> Scaffold-DbContext "Server=Laptop-tjj7d977;Database=Northwind;Integrated Security=true;TrustServerCertificate=True;" Microsoft.EntityFrameworkCore.SqlServer -OutputDir Models -F

Life time leases for the application instance:
AddTransient : for each reqquest
AddScopped : for a session
AddSingleton : for all request


2. Code First Approach :

-Create an MVC application
-Add Model class/es to the models folder
-Add a Connection string in appsettings.json file
-Create a Context Class and make an entry of the model classes
-Register the DbContext class along with Sqlservices in the program.cs file
-Build once
-in the PM Console, migrate using
   Add-Migration "<name>"
   Update-database
Then you can create respective controllers and perform actions
