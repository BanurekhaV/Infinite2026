1. Data redundancy and inconsistency
2. Difficulty in accessing data
3. Data Isolation - multiple files and formats
4. Integrity Problems
5. Atomicity of updates (no partial transactions)
6. Concurrent access to users
7. Security

Integrity Constraints : are rules enforced on the data columns of a table. These are used to limit the type of data that can go into the table. This ensures accuracy, reliability and integrity
3 types
 1. Domain Integrity : check, default, null
 2. Entity Integrity : every table to have a Primary key that is neither null nor duplicates, in order to identify a unique tuple. Primary Key
 3. Referential Integrity : a tuple in one relation refers to another relation - Foreign Key (always takes values that are in the primary key or can take nulls)

SQL - Structured Query Language
 Components of SQL
  - DDL (Data Definition Language - create, alter, drop, truncate)
  - DML (Data Manipulation lang  - insert, update, delete)
  - DQL (Data Query Lang - select)
  - DCL ( Data Control Lang - grant, revoke)
  - TCL ( Transaction Control Lang - commit, rollback)

Identity Column : can be applied to integer type of columns. This acts like a primary key, since 
  - it is inserted automatically by the system
  - it cannot have null
  - it increments the next number and hence cannot have duplicates
